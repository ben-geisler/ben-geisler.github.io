# `_talks`

Empty on purpose. One Markdown file per talk, named `YYYY-MM-DD-slug.md`:

```markdown
---
title: "Talk title"
collection: talks
type: "Talk"            # or "Conference proceedings talk", "Tutorial", "Keynote"
permalink: /talks/YYYY-MM-DD-slug
venue: "Hosting institution or conference"
date: YYYY-MM-DD
location: "City, Country"
---

Optional longer description, rendered on the talk's own page.
```

After adding the first talk, re-add a Talks entry to `_data/navigation.yml`.
