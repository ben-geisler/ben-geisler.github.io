# `_posts`

Empty on purpose. One Markdown file per blog post, named `YYYY-MM-DD-slug.md`:

```markdown
---
title: 'Post title'
date: YYYY-MM-DD
permalink: /posts/YYYY/MM/slug/
tags:
  - tag one
  - tag two
---

Post body in Markdown.
```

Posts are listed at `/year-archive/`. After adding the first post, re-add a
Blog Posts entry to `_data/navigation.yml`.
