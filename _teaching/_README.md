# `_teaching`

Empty on purpose. Teaching is currently summarised by hand on `/cv/`. To use
this collection instead, add one Markdown file per course, named
`YYYY-term-slug.md`:

```markdown
---
title: "Course name"
collection: teaching
type: "Graduate course"      # or "Undergraduate course", "Workshop"
permalink: /teaching/YYYY-term-slug
venue: "University, Department"
date: YYYY-MM-DD             # course start date
location: "City, Country"
---

Course description in Markdown.
```

After adding the first course, re-add a Teaching entry to
`_data/navigation.yml`.
